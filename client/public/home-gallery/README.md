# ภาพหน้าแรก (Home Gallery / Hero)

## ภาพใหญ่หัวเว็บ (เลื่อนได้)
แก้รายการใน `src/lib/home-media.ts` → `homeHeroSlides`
วางไฟล์แล้วใส่พาธ เช่น `/home-gallery/hero-01.jpg`
แนะนำอัตราส่วนกว้างประมาณ 21:9 หรือ 1920x800

## กริดกิจกรรม
แก้ที่ `homeGalleryItems`
แนะนำประมาณ 1200x750 (ใกล้ 16:10)

## YouTube
ใส่ลิงก์ 1 คลิปใน `homeYoutube.url`
ว่างไว้จะแสดงช่องว่าง — iframe จะโหลดเมื่อผู้ใช้กดเล่นเท่านั้น (ลด error จากตัวบล็อกโฆษณา)
