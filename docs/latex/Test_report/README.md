# รายงานการทดสอบ (Test_report) — เคสจริง

โฟลเดอร์นี้เป็น**ที่เขียนสถานการณ์ทดสอบจริง**ของ NUCare  
ต้นแบบว่างอยู่ที่ `../Template_TestReport_2026/` — อย่าใส่เคสจริงเฉพาะในเทมเพลต

## Compile

- **Overleaf**: อัปโหลดทั้งโฟลเดอร์นี้ แล้วตั้ง Compiler = **XeLaTeX**
- **เครื่องตนเอง**: จากโฟลเดอร์นี้รัน `latexmk main.tex`

## เพิ่ม / อัปเดตสถานการณ์

1. คัดลอก `scenarios/_template.tex` เป็น `scenarios/tcXX-ชื่อสั้น.tex` (หรือแก้ไฟล์เดิม)
2. กรอก `\tcmeta` / `\tcname` / `\tccase` ให้ครบ
3. ใน `main.tex` เพิ่มแถวสรุป + `\input{scenarios/tcXX-ชื่อสั้น}`

### นโยบายเขียนทับ

| สถานการณ์ | ทำอย่างไร |
|-----------|-----------|
| อัปเดตฟังก์ชันแล้วเทสใหม่ | เขียนทับทั้งไฟล์ scenario ของ TC นั้น |
| เทสซ้ำโดยไม่เปลี่ยนฟังก์ชัน | แก้เฉพาะวันที่, ผลลัพธ์จริง, ผลการทดสอบ และแถวสรุปใน `main.tex` — ไม่เก็บประวัติรอบเก่า |

## โครงสร้าง

| ไฟล์ / โฟลเดอร์ | ใช้ทำ |
|---|---|
| `main.tex` | ปก สรุปผล และ `\input` สถานการณ์ |
| `testreport.sty` | คำสั่งตารางเทส + ฟอนต์ |
| `scenarios/` | หนึ่งไฟล์ต่อหนึ่งสถานการณ์ |
| `theme/` | ฟอนต์ TH Sarabun New + โลโก้ |
