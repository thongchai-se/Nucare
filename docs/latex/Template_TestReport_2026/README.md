# Template รายงานการทดสอบ (Test Scenario / Test Case)

โฟลเดอร์เอกสารเทสแยกจากเล่มคู่มือ ใช้เก็บตารางสถานการณ์ทดสอบตามรูปแบบในเล่มรายงานโครงงาน
(หัวตาราง metadata + ตารางกรณีทดสอบ 6 คอลัมน์)

## เริ่มใช้งาน

- **Overleaf**: อัปโหลดทั้งโฟลเดอร์นี้ แล้วตั้ง Menu > Settings > Compiler = **XeLaTeX**
- **เครื่องตนเอง**: จากโฟลเดอร์นี้รัน `latexmk main.tex`

## โครงสร้าง

| ไฟล์ / โฟลเดอร์ | ใช้ทำ |
|---|---|
| `main.tex` | ข้อมูลปก สรุปผล และ `\input` สถานการณ์ทดสอบ |
| `testreport.sty` | ฟอนต์ TH Sarabun New, ปกย่อ, คำสั่งตารางเทส |
| `scenarios/` | หนึ่งไฟล์ต่อหนึ่งสถานการณ์ทดสอบ |
| `theme/fonts/` | TH Sarabun New |
| `theme/kku-logo.png` | โลโก้บนปก (ลบออกจากปกได้) |

## เพิ่มสถานการณ์ทดสอบ

1. คัดลอก `scenarios/tc01-login.tex` เป็นไฟล์ใหม่ เช่น `scenarios/tc03-xxx.tex`
2. แก้เลขตาราง / รหัส TC / ชื่อ / ขั้นตอน / ผลลัพธ์
3. ใน `main.tex` เพิ่ม `\input{scenarios/tc03-xxx}`
4. อัปเดตตารางสรุปด้านบนใน `main.tex`

### โครงคำสั่ง

```latex
\begin{testscenario}{เลขตาราง}{เลขสถานการณ์}
  \tcmeta{TC01}{CS 2568/01}{ชื่อโปรแกรม}{ผู้ทดสอบ}{วันที่ ...}{1.0}
  \tcname{ชื่อสถานการณ์การทดสอบ}
  \tcpre{ข้อกำหนดเบื้องต้น}
  \tcdesc{คำอธิบาย}
  \tccase{1}{กรณีทดสอบ}{%
    \begin{tcsteps}
      \item ขั้นตอนที่ 1
      \item ขั้นตอนที่ 2
    \end{tcsteps}}{ผลลัพธ์ที่คาดหวัง}{ผลลัพธ์จริง}{Pass}
\end{testscenario}
```

คอลัมน์ตารางกรณีทดสอบ: **ลำดับ | กรณีทดสอบ | ขั้นตอน | ผลลัพธ์ที่คาดหวัง | ผลลัพธ์จริง | ผลการทดสอบ**

## ปก

`\maketestcover` สร้างปกย่อหัวข้อ **รายงานการทดสอบ**  
ถ้าไม่ต้องการปก ให้ลบหรือคอมเมนต์บรรทัด `\maketestcover` ใน `main.tex`
