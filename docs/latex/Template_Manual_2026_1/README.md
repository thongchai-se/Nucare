# Template เล่มคู่มือการใช้งาน (User Manual)

สำหรับโครงงานคอมพิวเตอร์ สาขาวิชาวิทยาการคอมพิวเตอร์ วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น

เล่มคู่มือการใช้งานส่งพร้อมระบบที่นักศึกษาพัฒนา เพื่อให้ผู้อื่นติดตั้ง ใช้งาน ดูแล และพัฒนาระบบต่อได้โดยไม่ต้องถามผู้จัดทำ Template นี้ใช้รูปแบบหน้า ฟอนต์ หัวข้อ ตาราง ภาพ สารบัญ และเอกสารอ้างอิงชุดเดียวกับเล่มรายงานโครงงาน (`cskkucore.sty`) และเพิ่มคำสั่งสำหรับเขียนคู่มือ ตัวอย่างในเล่มเป็นคู่มือของระบบ "CS KKU Project Manager" ให้เขียนตามโครงเดียวกันแล้วแทนเนื้อหาด้วยระบบของตนเอง

## เริ่มใช้งาน

- **Overleaf**: Upload Project > `Template_Manual_2026.zip` แล้วตั้ง Menu > Settings > Compiler = **XeLaTeX**
- **เครื่องตนเอง**: `latexmk main.tex`

## แนวทางการเขียนในเล่ม (ตัวเลือก `guides`)

`main.tex` เปิดตัวเลือก `\documentclass[guides]{cskkumanual}` ไว้ ระหว่างเขียนเล่มจะเห็น

- หน้า **แนวทางการเขียนเล่มคู่มือการใช้งาน** ต่อจากสารบัญ: ผู้อ่าน 3 กลุ่ม โครงสร้างเล่ม การปรับตามประเภทโครงงาน (เว็บ มือถือ โปรแกรมบนคอมพิวเตอร์ IoT งานวิจัย/AI) หลักการเขียน และรายการตรวจก่อนส่ง
- กล่องสีม่วงเส้นประ **แนวทางการเขียน** ต้นแต่ละบท บอกว่าบทนั้นต้องมีอะไร
- ข้อความเตือนที่หัวกระดาษทุกหน้าว่าเป็นฉบับร่าง

**ก่อนส่งเล่มให้ลบคำว่า `guides`** (`\documentclass{cskkumanual}`) หน้าแนวทาง กล่องแนวทาง และข้อความเตือนจะหายไปเอง โดยเลขตารางและเลขภาพยังเหมือนเดิม นักศึกษาใช้ `\begin{guide}[หัวกล่อง] ... \end{guide}` จดบันทึกในทีมได้ กล่องเหล่านี้ไม่พิมพ์ในฉบับส่งเช่นกัน

## โครงสร้างเล่ม

คู่มือหนึ่งเล่มมีผู้อ่าน 3 กลุ่ม จึงแยกบทตามกลุ่มผู้อ่าน

| บท | เนื้อหา | ผู้อ่านหลัก | ไฟล์ตัวอย่าง |
|---|---|---|---|
| คำนำ ประวัติการแก้ไขเอกสาร | ระบบอะไร รุ่นใด ใครควรอ่านบทใด | ทุกกลุ่ม | `preface.tex`, `revision-history.tex` |
| 1 ภาพรวมของระบบ | ระบบทำอะไร ผู้ใช้และสิทธิ์ วิธีอ่านคู่มือ สัญลักษณ์ | ทุกกลุ่ม | `ch1-overview.tex` |
| 2 ความต้องการของระบบและการติดตั้ง | ฮาร์ดแวร์ ซอฟต์แวร์ ขั้นตอนติดตั้ง ตัวแปรตั้งค่า การตรวจสอบหลังติดตั้ง | ผู้ดูแลระบบ นักพัฒนา | `ch2-requirements.tex` |
| 3 การเริ่มต้นใช้งาน | สมัครสมาชิก เข้าสู่ระบบ ส่วนประกอบหน้าจอหลัก | ผู้ใช้งานทั่วไป | `ch3-getting-started.tex` |
| 4–5 การใช้งานตามบทบาท (คู่มือผู้ใช้งานทั่วไป) | หนึ่งบทต่อหนึ่งบทบาท หนึ่งหัวข้อต่อหนึ่งงาน | ผู้ใช้งานทั่วไป | `ch4-student.tex`, `ch5-advisor.tex` |
| 6 การดูแลระบบ | ผู้ใช้และสิทธิ์ สำรอง/กู้คืนข้อมูล ปรับรุ่น ตรวจสถานะ ความปลอดภัย | ผู้ดูแลระบบ | `ch6-administration.tex` |
| 7 คู่มือสำหรับนักพัฒนา | สถาปัตยกรรม โครงสร้างโค้ด สภาพแวดล้อมพัฒนา การทดสอบ ฐานข้อมูล API แนวทางพัฒนาต่อ การนำขึ้นใช้งาน | นักพัฒนา | `ch7-developer.tex` |
| 8 การแก้ไขปัญหาเบื้องต้น | ปัญหาของผู้ใช้ ปัญหาการติดตั้งและดูแลระบบ คำถามที่พบบ่อย ช่องทางติดต่อ | ทุกกลุ่ม | `ch8-troubleshooting.tex` |
| ภาคผนวก | อภิธานศัพท์ รายการ API | นักพัฒนา | `appendix-a-glossary.tex`, `appendix-b-api.tex` |

## คำสั่งเฉพาะเล่มคู่มือ

**ภาพหน้าจอพร้อมหมายเลขกำกับ**

```latex
\begin{screenshot}[width=0.6\linewidth]{images/login.png}{หน้าเข้าสู่ระบบ}{fig:login}
  \callout{0.94}{0.49}{1}                        % หมายเลขที่ตำแหน่ง (x, y)
  \calloutline{0.845}{0.555}{0.845}{0.625}{3}    % หมายเลขพร้อมเส้นชี้ไปยังจุด
  \highlight{0.10}{0.735}{0.80}{0.095}           % กรอบเน้น (x, y, กว้าง, สูง)
\end{screenshot}
\begin{calloutlist}
  \item คำอธิบายหมายเลข 1
\end{calloutlist}
```

พิกัดเป็นสัดส่วนของภาพ 0–1 วัดจากมุมซ้ายบน วิธีหาพิกัด: ใส่ตัวเลือก `grid` ชั่วคราว (`\begin{screenshot}[grid]{...}`) อ่านค่าจากเส้นตาราง แล้วลบ `grid` ออก ภาพที่กว้างแต่เตี้ย เช่น แถบเมนู ให้ครอปเฉพาะส่วนนั้นและวางหมายเลขนอกภาพด้วยค่า y มากกว่า 1

**ขั้นตอนและกล่องข้อความ**

```latex
\begin{steps}
  \item คลิก \btn{สมัครสมาชิก}
  \item กรอก \field{อีเมล} แล้วกด \keys{Ctrl+S}
        \result{ระบบแสดงหน้ารายการโครงงาน}
\end{steps}
\begin{note} ... \end{note}   \begin{tip} ... \end{tip}
\begin{warning} ... \end{warning}   \begin{important} ... \end{important}
```

**องค์ประกอบในเนื้อความ**: `\btn{ปุ่ม}` `\field{ช่อง}` `\keys{Ctrl+Shift+Z}` `\menu{แทรก > ภาพ}` `\calloutmark{2}` `\cmd{npm run dev}` `\filename{server/.env}` (ใน `\cmd` และ `\filename` ให้เขียน `# % &` เป็น `\# \% \&` ส่วน `_ ~ $` ใช้ได้เลย)

**คำสั่งและไฟล์ตั้งค่า**: `\begin{terminal} ... \end{terminal}` และ `\begin{codefile}[language=bash]{ชื่อไฟล์} ... \end{codefile}` สำหรับโค้ดจริงจากโปรเจกต์ใช้ `\begin{lstlisting}[caption={...},label={lst:...}]` (ตัวอย่างในบทที่ 7)

**ตารางสำเร็จรูป** (ตัดข้ามหน้าได้ พิมพ์ "(ต่อ)" ให้อัตโนมัติ)

| คำสั่ง | ใช้ทำ |
|---|---|
| `\begin{troubleshooting}[ชื่อตาราง][label] \problem{อาการ}{สาเหตุ}{วิธีแก้}` | ตารางแก้ปัญหา |
| `\begin{envtable}[ชื่อตาราง][label] \envvar{ชื่อ}{ค่าตัวอย่าง}{คำอธิบาย}` | ตัวแปรตั้งค่า |
| `\begin{faq} \question{คำถาม} คำตอบ` | คำถามที่พบบ่อย |
| `\begin{glossarylist} \term{คำ}{ความหมาย}` | อภิธานศัพท์ |
| `\begin{revisionhistory} \revision{ฉบับ}{วันที่}{รายละเอียด}{ผู้แก้ไข}` | ประวัติการแก้ไขเอกสาร |

ถ้าหัวข้อตามด้วยตารางยาวทันทีและหัวข้อตกอยู่ท้ายหน้า template จะย้ายหัวข้อไปขึ้นหน้าใหม่พร้อมตารางให้เอง (ต้องคอมไพล์ 2 รอบ ซึ่ง Overleaf และ `latexmk` ทำให้อยู่แล้ว)

**ข้อมูลระบบ**: กำหนด `\systemVersion{2.0}` และ `\systemURL{...}` ใน `main.tex` แล้วเรียกใช้ในเนื้อหาด้วย `\systemname` `\systemversion` `\systemurl`

## รายการและการจัดระยะ

รายการในเนื้อหาใช้ `enumerate` ทุกรายการ (เลข 1) 2) ... รายการซ้อนเป็น a) b) ...) ไม่ใช้ `itemize` (•) และไม่ต้องใส่ `[label=...]` เพราะ template กำหนดรูปแบบให้แล้ว ขั้นตอนการใช้งานใช้ `steps` และรายการย่อยในขั้นตอนใช้ `enumerate` ซึ่งแสดงเป็น a) b) ... ให้เอง ข้อที่มีชื่อให้ชื่อเป็นตัวหนาแล้วขึ้นบรรทัดคำอธิบาย

```latex
\begin{steps}
  \item กรอกข้อมูลในแบบฟอร์มให้ครบทุกช่อง
        \begin{enumerate}
          \item \field{อีเมล} และ \field{รหัสผ่าน}
          \item \field{บทบาท} ของผู้ใช้
        \end{enumerate}
\end{steps}
\begin{enumerate}
  \item \textbf{ผู้ดูแลระบบ}\\*
        จัดการผู้ใช้ รายวิชา และกำหนดเวลาส่งงาน
\end{enumerate}
```

ไม่ต้องจัดระยะเองด้วย `\vspace` `\medskip` หรือ `\newline` ในเนื้อหา (`\newline` ใช้ได้เฉพาะในช่องตาราง) และไม่ต้องพิมพ์เลขนำหน้าชื่อหัวข้อเอง (template ใส่เลขหัวข้อให้) กล่องแนวทางการเขียน (`guide`) ใช้ `itemize` ได้เพราะไม่พิมพ์ในฉบับส่ง

ระบบตรวจรูปเล่มของสาขาตรวจเล่มคู่มือได้เช่นเดียวกับเล่มรายงาน โดยปรับรูปแบบตามกติกาข้างต้น และแจ้งเมื่อยังเปิดตัวเลือก `guides` ยังมีภาพหน้าจอที่ใช้ `grid` หรือยังมีเนื้อหาตัวอย่างของ template

## ตัวเลือกของ class

`guides` (แสดงแนวทางการเขียน) และตัวเลือกเดียวกับเล่มรายงาน เช่น `\documentclass[guides,plainnumbering,boldheadings]{cskkumanual}` (ดูรายการใน `main.tex`)

## สารบัญ

สารบัญแสดงบท หัวข้อ และหัวข้อย่อยระดับ 1 (เช่น 4.2.1) ช่วยให้ผู้อ่านหาขั้นตอนที่ต้องการได้เร็ว ถ้าต้องการเฉพาะหัวข้อหลักให้ใส่ `\setcounter{tocdepth}{1}` ใน `main.tex` สารบัญที่ยาวเกิน 1 หน้าจะมี "สารบัญ (ต่อ)" และหัวคอลัมน์ "หน้า" ในหน้าถัดไปให้อัตโนมัติ สมการที่ใส่ `\eqcaption{...}` จะมีสารบัญสมการให้เช่นเดียวกับเล่มรายงาน (ดู README ของเล่มรายงาน)
